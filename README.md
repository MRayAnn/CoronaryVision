# CoronaryVision

**End-to-End Coronary Artery Segmentation with Deep Learning**

## Overview

CoronaryVision is a computer vision project focused on the automatic segmentation of coronary arteries in X-ray angiography images using deep learning.

The project uses the publicly available **ARCADE dataset (MICCAI 2023)** and aims to develop a reproducible machine learning pipeline, from dataset exploration and preprocessing to model training, evaluation, and deployment.

The objective is to demonstrate practical skills in computer vision, deep learning, and ML software engineering.

## Project Objectives

- Explore and understand the ARCADE dataset and its annotations.
- Implement a U-Net architecture for binary coronary artery segmentation.
- Develop a reproducible training and evaluation pipeline using PyTorch.
- Evaluate segmentation performance using appropriate metrics, including Dice and IoU.
- Build an interactive demonstration using Gradio.
- Develop an inference API using FastAPI.
- Introduce software engineering practices, including automated testing, Docker, and CI/CD.
